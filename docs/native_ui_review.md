# Ревью нативного интерфейса, 24 октября 2026

Проверены незакоммиченная реализация QML-интерфейса и связанные изменения Python-плагина
на базе `2a56c45`. Исходный код STE Slicer использован как справочник; установленная копия
плагина в ходе этого ревью не обновлялась.

## Исправления

- Ручной экспорт и сброс настроек блокируют новые запросы, переключение и удаление проектов
  в нативном интерфейсе. Завершение ручной операции сохраняет события проекта.
- Смена проекта очищает вложения, черновик, принудительный режим и последний запрос для повтора.
- Смена папки результатов сохраняет текущий проект в прежней папке и очищает текущую сессию:
  история одного проекта больше не попадает в новый каталог под устаревшим идентификатором.
- Настройки нельзя менять во время запроса или ручного инструмента. Диалог остаётся открытым,
  если сохранение отклонено.
- Проверка введённых, но ещё не сохранённых реквизитов не помечает сохранённое подключение рабочим.
- События инвалидирования слайсинга очищают прежние время, расход и признак готовности.
- Отмена на последней итерации больше не превращается в ошибку лимита шагов.
- HTTP-ответ LLM закрывается после чтения.
- Экспорт G-code/3MF заменяет файл атомарно; при ошибке замены предыдущий результат сохраняется.
- Закрытие HTTP-сервера выполняется даже при исключении сохранения во время завершения приложения.
- Добавлены Windows CI с PyQt5, запуск CI для feature-веток, проверка QML на секреты
  и настраиваемый путь `KARFOGEN_SAMPLE_PARTS` для тестовых деталей.

## Проверка

Python 3.12.14, PyQt5 5.15.11 / Qt 5.15.2: 201 тест, без пропусков, включая семь
STL-образцов из предоставленной папки. Проверки Python 3.5 syntax, QML static и hygiene проходят.
Синтаксическая совместимость не заменяет запуск на Python 3.5.

QML-тест загружает реальную тему слайсера с заглушками UM, проверяет состояния интерфейса,
переключение вкладок, закрытие/открытие окна и сохранение PNG. Предупреждений QML нет.
Просмотрены рендеры чата и узкого окна на русском языке при масштабе 150%.

## Границы проверки

В этом ревью не выполнялся сквозной запуск LLM → слайсинг → экспорт в установленном STE Slicer.
Предыдущий smoke-тест автора подтверждает открытие окна и обработку сетевой ошибки, но не экспорт.
Скриншоты стенда и модульные тесты не подтверждают корректность получаемого производственного G-code.

Сохраняются ограничения: отмена между шагами; проект восстанавливает переписку, а не сцену;
PNG содержит видимую область окна. При параллельном использовании внешнего MCP/legacy API
и нативного окна нет общей транзакционной блокировки изменений сцены между этими клиентами.
Встроенные проекты и каталог результатов привязаны друг к другу; смена каталога не переносит архив.
