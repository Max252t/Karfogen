# AI Assistant для STE Slicer

Плагин добавляет в STE Slicer чат-бота. Пользователь описывает задачу печати, прикладывает изображения и 3D-модели,
а LLM через MCP-инструменты выбирает режим печати (3D / 5D Spiral / 5D), материал, профиль качества и настройки,
ориентирует модель, запускает слайсинг, сохраняет G-code и проект 3MF и объясняет принятые решения.

## Требования

- STE Slicer (форк Cura 3.6, API плагинов 5) с принтером Stereotech Hybrid 530 V5.2.4.
- Доступ к OpenAI-совместимому API (Chat Completions с tool calling).
- Сторонние пакеты Python не нужны: используются только стандартная библиотека и модули дистрибутива.

## Установка

Скопируйте папку `AIAssistant` в папку плагинов пользователя STE Slicer
(`%APPDATA%\steslicer\<версия>\plugins`, например `%APPDATA%\steslicer\7.10\plugins`) и перезапустите слайсер.
Пересобирать слайсер не нужно. Python-код и QML загружаются при запуске, поэтому после обновления плагина
слайсер нужно перезапустить.

## Запуск

Меню **Extensions → AI Assistant → Open chat** открывает нативное окно ассистента внутри STE Slicer.
Окно немодальное: со сценой можно работать, не закрывая его. Повторный выбор пункта меню активирует уже открытое окно.
Закрытие окна не останавливает ассистента; при повторном открытии переписка и прогресс на месте.
Размер и положение окна запоминаются.

Окно состоит из трёх вкладок:

- **Чат** — переписка, карточки действий ассистента, ошибки с кнопками «Повторить», «Открыть настройки», «Продолжить»,
  поле ввода (Enter — отправить, Shift+Enter — новая строка), вложения и режим печати;
- **Результат** — состояние задачи, режим, материал и профиль, принятые решения, изменённые параметры
  (название, старое → новое значение), прогресс и итоги слайсинга, сохранение G-code и 3MF;
- **Проекты** — список проектов с датой изменения и числом сообщений.

Полоса выполнения со статусом и кнопкой **Остановить** видна на любой вкладке, пока ассистент работает.

## Настройка

Кнопка с шестерёнкой (или индикатор подключения) в шапке окна открывает **Настройки подключения**:

- Base URL, модель и ключ API (OpenAI-совместимый API с поддержкой инструментов);
- **Проверить подключение** — короткий запрос с введёнными значениями, без сохранения;
- подробность объяснений, автоматическое сохранение G-code и 3MF после слайсинга, проверка сертификата;
- язык ассистента: русский, английский или «как в слайсере»;
- папка результатов (кнопка «Обзор…»).

Настройки сохраняются только после завершения текущего запроса или экспорта. При смене папки результатов
текущий диалог сохраняется в прежней папке, затем открывается пустой диалог. Старые проекты остаются
в прежней папке; чтобы снова увидеть их в списке, выберите её в настройках.

Пока подключение не настроено, вкладка «Чат» показывает экран первой настройки.

Адрес, модель и ключ можно также задать переменными окружения до запуска слайсера:

- `AI_ASSISTANT_BASE_URL` — адрес API, например `https://<host>/v1`;
- `AI_ASSISTANT_MODEL` — название модели;
- `AI_ASSISTANT_API_KEY` — ключ.

Ключ хранится в настройках слайсера и не показывается в интерфейсе целиком (только маска).

## Модель из сцены и вложения

Если в сцене уже есть модели, над полем ввода появляется **Использовать модель из сцены** с именем и габаритами.
При нескольких объектах можно отметить нужные или выбрать всю сцену. Ассистент получает `object_id` объектов
и не загружает модель повторно.

Новые файлы (STL, OBJ, 3MF, JPG, PNG, до 100 МБ) прикрепляются кнопкой с папкой или перетаскиванием в окно.
Изображения показываются превью; вложение можно убрать до отправки. Файл передаётся ассистенту по локальному пути.

Режим печати: **Авто** (по умолчанию, режим выбирает ассистент), **3D**, **5D Spiral**, **5D** — фиксируют выбор пользователя.

## Проекты

Переписка каждого проекта сохраняется на диск (`<results>/_projects`) после сообщения и по ходу работы ассистента.
На вкладке «Проекты» проект можно создать, открыть, переименовать и удалить (с подтверждением).
Пока имя не менялось вручную, оно берётся из имени модели или начала запроса.
Во время работы ассистента можно просматривать текущий проект, но не переключаться на другой.

Сцена в проекте не сохраняется. При создании нового проекта диалог предлагает очистить сцену и сбросить изменения
настроек (включено по умолчанию, чтобы настройки прошлой детали не перешли в новую); галочку можно снять.

## Экспорт

После слайсинга на вкладке «Результат» доступны **Сохранить G-code**, **Сохранить 3MF**, путь сохранённого файла,
**Открыть папку** и **Сохранить скриншот чата** (`chat_<n>.png` в папке модели).
G-code можно сохранить и после нарезки штатной кнопкой слайсера: ассистент следит за состоянием слайсинга.
Если открыт старый проект, его цифры помечаются как «Результат из истории проекта», а G-code сохраняется только
для текущей нарезанной сцены.
**Сбросить изменения настроек** отменяет пользовательские изменения слайсера после подтверждения.

## Пример запроса

> Кронштейн под нагрузку, PETG, без поддержек

с приложенным STL. Ассистент загрузит модель, проанализирует геометрию, выберет режим, материал и профиль,
применит настройки (4 периметра, заполнение 40%, поддержки выключены), подберёт ориентацию с минимумом нависаний,
нарежет модель, сохранит результаты и объяснит каждое решение.
На экране пустого проекта есть шаблоны запросов для типичных задач: их можно дополнить и отправить.

## Результаты

Папка результатов задаётся в настройках (по умолчанию `~/AIAssistantResults`):

```
<results>/<model_name>/project.3mf
<results>/<model_name>/result.gcode
<results>/<model_name>/chat_<n>.png
```

## Инструменты MCP

Те же инструменты, которыми пользуется встроенный агент, доступны внешним MCP-клиентам:
`POST http://127.0.0.1:8765/mcp` (JSON-RPC 2.0; если порт занят, выбирается свободный — он записан в журнале слайсера).
Нативное окно с HTTP-сервером не общается.
Список: `tools/list`. Проверка без LLM: `scripts/mcp_smoke.sh [порт]`.

Настройки и профили: `select_machine`, `get_machine`, `get_print_mode`, `set_print_mode`, `list_quality_profiles`,
`set_quality_profile`, `list_materials`, `set_material`, `get_setting`, `set_setting`, `set_settings`, `search_settings`,
`get_changed_settings`, `reset_settings`, `create_profile` (встроенному агенту не выдаётся).

Сцена: `load_model`, `list_objects`, `get_object_bounds`, `analyze_mesh`, `suggest_orientation`, `set_orientation`, `lay_flat`,
`align_symmetry_axis`, `rotate_object`, `move_object`, `scale_object`, `arrange_all`, `delete_object`, `clear_scene`.

Слайсинг и экспорт: `slice`, `get_slice_status`, `get_slice_result`, `export_gcode`, `save_project_3mf`.

Подбор по правилам: `recommend_setup`.

Координаты на столе: x вправо, y назад, z вверх, начало в центре стола, единицы — миллиметры.

## Типичные проблемы

- **Порт MCP занят** — плагин выберет свободный порт; строка `AIAssistant: server listening on` в журнале показывает его.
- **Слайсер не запускается, `Intel MKL ERROR: CPU ... is not supported`** — ошибка встроенной в дистрибутив библиотеки MKL
  на новых процессорах, к плагину не относится. Помогает запуск с переменной окружения `MKL_DEBUG_CPU_TYPE=5`.
- **401 / 403** — неверный ключ API.
- **404** — неверный адрес API или название модели.
- **SSL-ошибка (CERTIFICATE_VERIFY_FAILED)** — в плагин встроены корневые сертификаты из папки `certs` (GlobalSign Root R46), потому что у встроенного certifi слайсера они устарели. Для другого хоста положите корневой сертификат в формате `.pem` в `certs`. В крайнем случае проверку можно отключить настройкой `verify_ssl=false` (по умолчанию включена).
- **Слайсинг не стартует** — в сцене нет модели, модель вне рабочего объёма или настройки содержат ошибки валидации;
  подробности в `stderr.log` в папке конфигурации (сообщения плагина начинаются с `AIAssistant:`).
- **Не сохраняется проект или пропал чат** — смотрите строки `AIAssistant: could not save project` в `stderr.log`.

## Ограничения

- Код совместим с Python 3.5 (без f-строк и сторонних пакетов).
- Работа со сценой и настройками выполняется в главном потоке слайсера. Запись G-code и 3MF идёт из рабочего потока:
  записывающие модули слайсера сами переходят в главный поток, из него их вызывать нельзя.
- Режимы 5D требуют, чтобы ось симметрии детали была вертикальна; ассистент делает это инструментом `align_symmetry_axis`.
- Критерии выбора 5D и материалов — стартовые гипотезы базы знаний (`agent/knowledge.py`), их нужно уточнять по эталонным проектам.
- Остановка срабатывает между шагами: текущий запрос к LLM или слайсинг доводится до конца.
- Скриншот чата сохраняет видимую часть окна, а не всю прокрученную переписку.
- В теме слайсера одна (светлая) тема; окно берёт цвета из `UM.Theme`.
- Папка `web` и `/api/*` — устаревший браузерный интерфейс (legacy). Из слайсера он не открывается и оставлен для
  совместимости: страница по-прежнему доступна по адресу сервера.
